# Alan Sans static weights

Regular (400) and semibold (600) instances of the [Alan Sans](https://github.com/alan-eu/Alan-Sans) variable font in [public/fonts](../../../public/fonts/AlanSans.ttf), used by the social-card renderer. Satori's font parser requires static instances of this font.
