### Added

- The Experimental Zinn task inspector opens beside a Codex desktop conversation on macOS. Look up local tasks, read comments, follow relations and move tasks between columns in their project.
- Edit titles, descriptions and priorities with an explicit Save. If another client changes a field you edited, the inspector keeps your draft and lets you choose which value to keep before saving again.
- Optional hooks collect task references for the current chat and supply execution identity to supported direct Zinn commands.

Install from the Zinn Git marketplace on GitHub. The plugin requires Node.js 24.15.0 or newer and Zinn CLI 0.45.0 or newer. See [installation](/integrations/codex#install-from-github) and [macOS compatibility](/integrations/codex#compatibility).
