# CLI reference

Choose a topic for command behavior and examples. For your first project, start with the [Quick start](/docs/quick-start).

## Work with tasks

- [Create and find tasks](/docs/cli/tasks): create, list, filter, sort, inspect and search.
- [Edit and organize tasks](/docs/cli/editing): change content, move, order, archive and delete, set priorities and deadlines.
- [Next task and claims](/docs/cli/next): select ready work, claim it, renew a lease and release it.
- [Task blame](/docs/blame): find the recorded authors of fields and description lines.

## Manage the board

- [Projects and columns](/docs/cli/projects): create projects, name columns, set categories and change board order.
- [Labels](/docs/cli/labels): define labels and attach them to tasks.
- [Task relations](/docs/cli/relations): dependencies, subtasks, duplicates and related tasks.
- [Task comments](/docs/cli/comments): add, read, edit and delete comments.

## Rules and tools

- [Shared input rules](/docs/cli/conventions): editing, text from files or stdin, repeated flags and bulk changes.
- [Activity](/docs/cli/activity): read, filter and follow recorded changes.
- [Actor identity](/docs/cli/identity): inspect the actor, session and calling client.
- [Help and diagnostics](/docs/cli/help): command help, aliases, health checks and the agent skill.

For JSON contracts and unattended commands, see [Scripting and JSON output](/docs/scripting). [Settings](/docs/settings) covers configuration. [Data and backups](/docs/data) covers storage, backups and database upgrades.
