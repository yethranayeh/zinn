# Zinn documentation

Zinn is an Experimental kanban CLI and task manager for the terminal. Projects, columns and tasks live in a local SQLite database, and scripts and agents use the same commands with JSON output.

## Get started

- [Install](/docs/installation): install, upgrade and uninstall the CLI and core library.
- [Quick start](/docs/quick-start): create a project, add a task, and move it through the board.

## Reference

- [CLI](/docs/cli): project, task, label, relation, comment, and activity commands.
- [Task blame](/docs/blame): attribute a task's fields and description lines to the edits that set them.
- [Settings](/docs/settings): choose a data directory and default project.
- [Scripting and JSON](/docs/scripting): use JSON, discover commands, and handle confirmations.
- [Hooks](/docs/hooks): run commands after Zinn saves a change.
- [Data and backups](/docs/data): understand storage, backups, restores, and database upgrades.
